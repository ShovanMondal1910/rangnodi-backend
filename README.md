# Rangnodi Backend

Express.js backend with TypeScript for Rangnodi.

## Prerequisites

- [Node.js](https://nodejs.org/) (v20+ recommended)
- [npm](https://www.npmjs.com/)

## Installation

```bash
npm install
```

## Running the app

```bash
# development mode (auto-reload)
npm run dev

# build TypeScript
npm run build

# production mode
npm start
```

## Running tests

```bash
npm test
```
